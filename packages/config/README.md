# @chronos/config

Typed, fail-fast configuration. Services read the environment only through this package (lint bans `process.env` in `services/`, `restricted/` and `apps/`).

```ts
import { baseSchema, loadConfigOrExit, port, postgresUrl, secret } from '@chronos/config';
import { z } from 'zod';

const schema = baseSchema.and(
  z.object({
    PORT: port.default(3000),
    DATABASE_URL: postgresUrl,
    SIGNING_SECRET: secret(),
  }),
);

export const config = loadConfigOrExit(schema); // exits 1 with a clear message on bad config
const url = config.DATABASE_URL.reveal(); // secrets are wrapped
```

- **Fails fast and completely:** every missing or invalid variable is reported at once, by name. Error messages never contain values.
- **Secrets are wrapped:** `secret()`, `postgresUrl` and `redisUrl` return a `Secret` that prints `[REDACTED]` through `String()`, JSON and `util.inspect`. Call `reveal()` only where the raw value is needed.
- **File secrets:** for any declared variable `NAME`, setting `NAME_FILE=/path` reads the value from that file (Kubernetes or External Secrets mounts). Setting both is an error.
- **Data residency:** in staging and production `AWS_REGION` must be `af-south-1`.
- **Local development:** credentials come from environment variables (see `tools/.env`, generated by `pnpm dev:infra`). Deployed environments inject them from AWS Secrets Manager. Nothing secret is committed.
